# sys4 (System Info Monitor / 시스템 정보 모니터)

`sys4` is a lightweight, high-performance system resource monitoring application built with **Tauri**, **React**, and **Rust**. It provides real-time insights into your computer's performance with a sleek, modern interface.

`sys4`는 **Tauri**, **React**, **Rust**로 제작된 가볍고 강력한 시스템 리소스 모니터링 애플리케이션입니다. 세련되고 현대적인 인터페이스를 통해 컴퓨터의 성능을 실시간으로 확인할 수 있습니다.

## Key Features / 주요 기능

-   **CPU Monitoring**: Real-time usage tracking. (실시간 CPU 사용량 추적)
-   **Memory (RAM) Usage**: Total and available memory monitoring. (전체 및 사용 가능한 메모리 모니터링)
-   **GPU Monitoring**: Support for VRAM and load (NVIDIA/AMD/Intel). (VRAM 및 부하율 지원)
-   **Compact Design**: Minimalistic UI that doesn't clutter your workspace. (작업 공간을 방해하지 않는 미니멀한 UI)
-   **Widget Mode**: A tiny, always-on-top widget for continuous monitoring. (항상 위에 떠 있는 컴팩트 위젯 제공)

## How to Use / 사용 방법

1.  **Main Window (메인 창)**: Shows detailed statistics for CPU, Memory, and GPU. (상세 통계 표시)
2.  **Widget Toggle (위젯 전환)**: Click the widget icon in the title bar to switch to a compact floating widget. (타이틀 바의 아이콘으로 위젯 전환)
3.  **Expand/Collapse (확장/축소)**: Each section can be expanded for more detail or collapsed for a cleaner look. (각 섹션별 상세 정보 토글)
4.  **Auto-Update (자동 업데이트)**: The app automatically checks for new releases on GitHub. (GitHub 최신 버전 자동 확인)


## Development Stack / 개발 스택

-   **Frontend**: React + Vite
-   **Backend**: Rust (Tauri)
-   **Styling**: Vanilla CSS (Focus on dark mode and readability / 다크 모드 및 가독성 중심)
