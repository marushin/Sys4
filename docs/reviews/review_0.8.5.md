## 📋 프로젝트 개요

Tauri + React 기반의 초경량 시스템 리소스 모니터링 데스크톱 애플리케이션입니다.

## ✅ v0.8.5 핵심 개선 사항

### 1. 고DPI 및 Windows 텍스트 확대(125%~150%) 환경 완벽 대응
- **2열 그리드 및 페어 레이아웃 (`.sub-grid`, `.sub-item`)**: 서브 정보 행(`사용/전체`, `스왑/스왑 전체`, `온도/전력`)을 4개의 개별 `<span>` 나열 방식에서 2열 그리드와 개별 페어 컴포넌트로 전면 재설계했습니다.
- **단어 단위 분리 방지 (`nowrap` & `word-break: keep-all`)**: 폰트 크기나 창 너비 변화에 관계없이 `사/용`, `스/왑`, `전/체` 등 글자가 단어 중간에서 쪼개지던 현상을 원천 방지했습니다.
- **수치 말줄임 해제**: `52.2 GB`, `49.5 GB` 등의 수치 및 단위가 `...`으로 잘리지 않도록 스타일을 정돈했습니다.

### 2. 타이틀바 버튼 레이아웃 버그 완전 해결
- **`index.css` 레거시 버튼 스타일 충돌 제거**: Vite 템플릿 기본 보일러플레이트인 `#root button { padding: 0.6em 1.2em; }`가 높은 CSS 우선순위로 인해 타이틀바 버튼까지 부풀려 닫기(`✕`) 버튼을 화면 밖으로 밀어내던 버그를 완전히 제거했습니다.
- **컴팩트 버튼 규격 확립**: 타이틀바 버튼 4개를 각각 `28px`(총 112px)로 고정하고 `flex-shrink: 0`을 적용하여 닫기(`✕`) 및 최소화(`─`) 버튼이 항상 100% 노출되도록 보장했습니다.

### 3. 창 크기 및 렌더링 동기화 고도화
- **기본 너비 260px 최적화**: 고해상도 및 텍스트 확대 설정에서도 쾌적한 가독성을 제공하도록 기본 창 너비를 260px로 조정했습니다.
- **`ResizeObserver` + 서브픽셀 안전 버퍼 연동**: 내용물 높이 변화를 실시간 감지하여 창 크기를 동기화하며, 고DPI 소수점 픽셀 반올림으로 인한 창 하단 1~2px 잘림을 방지했습니다.
- **글로벌 `box-sizing: border-box` 표준화**: 전체 CSS에 표준 박스 모델을 적용하여 일관된 크기 계산을 보장합니다.
